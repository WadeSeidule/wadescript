# WadeScript Roadmap

## Data Structures
- Sets (`set[T]`)

## Standard Library
- OS module (env vars, path manipulation, process management)
- Expanded CLI module (decorator-based argument parsing, subcommands)

## Language Features
- List/dict comprehensions
- Pattern matching (match/switch)
- Lambdas / anonymous functions
- Class inheritance
- User-defined exception types
- For-loop iteration over arrays
